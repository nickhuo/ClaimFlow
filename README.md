# ClaimFlow

Conversational insurance claims support with an explicit SOP controller, protected-data gates, cross-phase memory, and optional email follow-up.

The project uses TypeScript throughout and Bun for its runtime, dependencies, scripts, and tests. The selected architecture and acceptance criteria are in [brief.md](brief.md).

## Repository contents

- `brief.md`: requirements, architecture, safety gates, evaluation plan, and delivery criteria.
- `insurance_claims/fixtures/`: supplied identity, claims, authorization, and document-guidance test data.

The repository currently contains the project brief and starter data. The agent, UI, package configuration, and Docker setup will be added during implementation.
